# pickamodel.dev

pickamodel.dev helps developers pick the model for the coding job — not the hype thread. It is a small collection of decision pages for common coding-agent tasks.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The production site is intended for [pickamodel.dev](https://pickamodel.dev).
